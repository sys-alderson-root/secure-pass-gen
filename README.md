# fs0ciety - Secure Password Generator 🔐

A lightweight and secure password generator written in Python.

## 🚀 Features
- Generates strong passwords using `random.SystemRandom()` (cryptographically secure).
- Customizable length.
- Includes uppercase, lowercase, numbers, and special characters.
